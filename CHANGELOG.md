## [v0.1.0] - 2026-08-22

### Highlights

- Initial GuardSQL release with a SaaS-safe parser, AST, schema validation, policy checks, formatter, and in-memory evaluator
- Browser-side TypeScript package and optional SystemForge authorization adapter for application integrations

### Added

- Read-only GuardSQL parser and AST for SELECT/FROM/WHERE/GROUP BY/HAVING/ORDER BY/LIMIT, CTEs, joins, nested sources, aggregate functions, and PRIORITIZE BY ([`0658bf3`](https://github.com/grokify/guardsql/commit/0658bf3))
- Schema validation, static linting, policy checks, query analysis, safe analytics policy defaults, and field requirement extraction ([`0658bf3`](https://github.com/grokify/guardsql/commit/0658bf3))
- In-memory evaluator for single-source filtering, grouping, aggregates, HAVING, ordering, limits, and projection ([`0658bf3`](https://github.com/grokify/guardsql/commit/0658bf3))
- Dependency-free formatter and guardsqlfmt CLI for canonical query output, single-line formatting, and ANSI highlighting ([`0658bf3`](https://github.com/grokify/guardsql/commit/0658bf3))
- Lightweight authorization decision helpers and optional nested SystemForge authorization adapter module ([`f6735ae`](https://github.com/grokify/guardsql/commit/f6735ae))
- Browser-oriented TypeScript package with lexer, parser, formatter, schema validation, policy checks, tests, and generated distribution files ([`c3fe38c`](https://github.com/grokify/guardsql/commit/c3fe38c))

### Fixed

- Reject AS without a following alias so malformed source aliases fail parsing and golangci-lint unparam remains clean ([`21bdb16`](https://github.com/grokify/guardsql/commit/21bdb16))

### Documentation

- Documented query language syntax, request pipeline, schema validation, policy model, authorization, backend execution, integrations, development, and security hardening guidance ([`d2425e0`](https://github.com/grokify/guardsql/commit/d2425e0))
- Added README status shields ([`150bc0a`](https://github.com/grokify/guardsql/commit/150bc0a))

### Build

- Ignored generated MkDocs site output ([`d4b4a64`](https://github.com/grokify/guardsql/commit/d4b4a64))
